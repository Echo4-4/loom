Loom help

Loom is a private dashboard for Git and GitHub. It runs only on your machine (127.0.0.1) and shows every git command it runs.

Quick start

  1. Paste your repo folder in the top box and click Open.
  2. Click + beside a file (or Add all) to stage it.
  3. Write a message and click Commit.
  4. Click Push.

See a repo as a tree

Opening a local folder shows its files in the Tree tab. To map a GitHub repo, paste its link in the top box or drag the link onto the page. For private repos or rate-limit errors, put a token in the token box first. Copy tree copies a text version.

Push over HTTPS

  1. On GitHub: Settings → Developer settings → Personal access tokens. Create a fine-grained token with Contents: Read and write for your repo.
  2. Paste https://github.com/you/repo.git in the Remote box and click Set.
  3. Paste the token in the token box and click the orange Push. The first push sets the upstream branch for you.

The token stays in this page's memory and is passed to git for that one push. It is not saved in .git/config (needs git 2.31+). To avoid pasting it, run git config --global credential.helper store in a terminal, push once there, then use the normal Push button.

Buttons

Fetch checks the remote. Pull brings changes in. Stash shelves your edits and Pop brings them back. Init makes a new repo. Click a branch to switch, or type a name and + to create one. The bottom box runs any git command.

Terminal

python loom.py help
python loom.py /path/to/repo
python loom.py --port 9000 --no-browser

Shortcuts: Ctrl/Cmd+K opens the command palette, which lists each action's key. Esc twice resets the view. ? opens this page, Esc closes it. The ☀ button switches light and dark.
